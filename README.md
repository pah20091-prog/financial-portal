# Reward Budget Financial Portal

개인용 통합 금융 포털입니다.

## 포함 영역
- 통합 금융 홈
- 은행 계좌
- 카드 및 결제
- 리워드 및 포인트
- 자산 및 투자
- 구독 및 멤버십
- 파일 가져오기와 JSON 백업

## GitHub Pages 배포
1. 이 ZIP의 파일을 GitHub 저장소 최상단에 업로드합니다.
2. GitHub 저장소에서 Settings > Pages로 이동합니다.
3. Source를 Deploy from a branch로 선택합니다.
4. Branch는 main, Folder는 /(root)로 설정합니다.
5. 이후 index.html을 교체하고 Commit 및 Push하면 사이트가 자동 재배포됩니다.

## 데이터 저장
입력한 데이터는 브라우저 LocalStorage에 저장됩니다. 정기적으로 앱의 JSON 백업 기능을 사용하세요.
